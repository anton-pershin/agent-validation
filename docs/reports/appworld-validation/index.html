04 · Privacy and scoring

Public execution stops before private evaluation starts

AppWorld’s ordinary guards are not a private-data boundary. The execution worker therefore uses Landlock, then exits. A different trusted process performs evaluation without agent code.

🛡️ Execution worker can use

  • Public instruction, supervisor fields, and app descriptions
  • Public task databases and API documentation
  • The pinned runtime and its own episode output
  • Episode-local temporary files only

A per-episode self-test must prove that the task’s ground-truth directory cannot be opened.

⛔ Execution worker cannot use

  • Ground truth, answers, and reference solutions
  • Private evaluation code or evaluation reports
  • Provider or provisioning credentials
  • Other tasks, unrelated host paths, or other episodes

Only the separate trusted evaluator receives private-data access, after public execution has closed.

Success is a three-part decision

1

Protocol declaration

The solution sends a valid final response with completed=true and self-assessment.

2

AppWorld completion

The solution called apis.supervisor.complete_task(...). This call alone never ends the episode.

3

Independent evaluator

The private evaluator’s programmatic tests pass. Otherwise the episode is unsuccessful.

05 · Evidence and resources

Frugal by default, configurable by design

Memory depends on active workers, not the 630-episode total. The default is one worker, while profile and service-wide concurrency settings remain configurable for larger machines.

Measured no-op baseline
659–660 MiB

Peak RSS for one real AppWorld worker across probes from train, dev, and test_normal.

Illustrative scale: 3 GiB host hard limit, not expected use and not an upper bound for agent code.

Operational evidence
  • About 7.1 CPU-seconds per fresh no-op worker lifecycle
  • Configured and actual package/data versions in evidence
  • Landlock ABI and execution/evaluator resource observations
  • Private evaluation result and report retained outside the solution protocol
  • Partial startup and abort paths preserve available diagnostics
  • Temporary experiment output is removed after evidence is retained

What to remember

Full

630 episodes at concurrency one have a 52.5-hour maximum episode-time budget at 300 seconds each. Model latency dominates real runs.

Partial

Iterate on one task or any subset. Keep at least two repeats for AC3, or remove AC3 from a one-repeat diagnostic run.

Scale

Increase episode_concurrency and service-wide capacity only after measuring real solution memory and CPU on the target host.
